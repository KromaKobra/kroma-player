# v1.3.0 Changelog

</div>

## Highlights

### Sidebar Navigation

> The navbar is now a sidebar. It collapses and expands, resizes more intuitively, and the right sidebar was updated to match the left. Both sidebars pick up the ambient artwork behind them. The dark header bar was removed and the app header bar was improved.

### Color Theme Follows Cover Art

> The color theme can now take its colors from the cover art of the track that is playing. The "follow the artwork" setting in Settings → Appearance is on by default.

### Songs Tab Redesign

> The songs tab was redesigned and gained an index column. Click a column header to sort by that column. The other library tabs were adapted to the same track list. Track lists now behave the same way everywhere, and the library tabs have a sorting button.

---

## Features

- **Library tab sorting button**
- **Click column headers to sort the songs tab**
- **Songs list index column**
- **Unified track list behavior across library tabs**
- **Compact mode for list view on track lists**
- **Adjacent selected tracks join at the corners**
- **Navbar collapse button dynamics**
- **Updated settings page**
- **Faster UI while resizing the window**
