## Highlights

### Massive Album Overhaul

> Albums have grown up alongside artists: a track can belong to more than one of them, an album can be identified against a real release and told what it is missing, tracks already in your library can be claimed onto an album a search just found, and an album that holds the whole release says so. Album and artist pages were remodelled after the playlist detail view, and an album can now hide its artwork.

### yt-dlp Is Now Yours

> yt-dlp is no longer bundled inside the application. It is a program you install, found on `PATH` next to ffmpeg and deno, which means it is updatable on its own schedule rather than frozen at whatever the last Kroma build happened to ship. YouTube's extractor churn breaks a months-old copy on a scale of weeks, and this makes fixing that one command you already have. Settings → Dependencies reports whether it is installed, which executable was resolved, and whether it is old enough to start failing.

### Lyric Editing Revamp

> Lyrics can now be edited manually, line by line, or with a retime feature for synced lyrics. Lyric timing can be manually adjusted or retimed completely.
