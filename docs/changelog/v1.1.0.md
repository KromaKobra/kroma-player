## Highlights

### Linux Support!

> Kroma Player now runs natively on Linux, including a first-class NixOS package. Media keys and desktop media controllers are supported through MPRIS2 over DBUS, so play, pause, and skip work from your desktop environment, lock screen, or keyboard just like any other native player.

### Artists Are Now Real!

> Artists have been promoted from plain text into full identities. Every artist is searchable, viewable, and editable, can carry its own image, and can be tagged with a YouTube ID. The library tab now has a dedicated list of all your artists. Track artist fields are tags instead of free text, so you can add, remove, and reorder the artists on a track.

### Import Overhaul!

> Importing has been rebuilt around its own dedicated tab. You can now import straight from a YouTube link, pull local files in from a web search, and mix local and web sources together in a single import list. New imports append to the list instead of replacing it, with a scroll and flash so you can see what landed, and a source column plus legend select makes it clear where each track came from.

### Backup Sync!

> Your library can now be backed up and kept in sync, so your tracks and metadata survive a move to a new machine or a bad day.
